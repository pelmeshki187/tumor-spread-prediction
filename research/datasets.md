# Кандидаты датасетов — сводка и ранжирование

В таблице 81 датасет; строки отсортированы по убыванию предварительной оценки пригодности для работы по прогнозированию распространения опухоли. Оценки основаны на описаниях источников и служат для выбора кандидатов на проверку. Файлы датасетов не аудировались; высокий балл не гарантирует наличие готовой выборки для выбранной задачи.

**Критерии оценки и максимальные баллы:** З — связь с прогнозом (25); П — повторные обследования и последующее клиническое наблюдение (20); Р — разметка опухоли (15); К — клинические данные и исходы (10); N — число независимых пациентов (10); Д — доступность данных (10); В — вычислительная доступность (5); М — приоритет рака молочной железы (5). Подробная шкала приведена после таблицы.

Ссылки ведут на страницы коллекций, публикации или указанные зеркала. Объём относится к указанной коллекции или подвыборке; он не включает дополнительное место для распаковки и обработки. Число пациентов в архиве может отличаться от числа пациентов, пригодных для эксперимента.

Столбец «Потенциальное применение в работе» описывает задачу для каждого датасета. Наличие необходимых меток и способ их получения нужно проверить по исходным файлам. Статус «Не проверен» означает, что пригодность файлов для эксперимента ещё не подтверждена.

Итоговый балл — сумма восьми компонентов. Шкала используется для предварительного сравнения; после проверки файлов, доступных исходов и числа подходящих пациентов оценки нужно пересчитать.

| П: продольность | 20 | 0: нет повторов/исходов; 5: наблюдение без снимков; 10: исходная визуализация + клинический исход или редкие пары; 15: преимущественно две точки; 20: 3+ дат у значимой части пациентов |
