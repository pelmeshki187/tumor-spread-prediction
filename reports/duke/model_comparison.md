# Duke: сравнение пяти survival-моделей

674 пациента / 47 отдалённых рецидивов; 20 повторных пятиблочных разбиений. Все методы обучены заново на общих блоках с обработкой признаков только по обучающим пациентам. Исход, цензурирование и метрики соответствуют [протоколу](../../research/duke-protocol.md).

## Фиксированные методы

Три Cox-модели: возраст, log-объём, возраст + log-объём; alpha=0, ties=Efron. Лес и бустинг получают возраст и log-объём. Медиана и стандартизация обучаются в каждом блоке отдельно для каждой модели. Дополнительных признаков нет.

Random Survival Forest: 200 деревьев, глубина 3, минимум 20 пациентов в листе, 40 для разделения, оба признака доступны при разделении, bootstrap=True. Бустинг: Cox loss, 100 деревьев глубины 1, learning_rate=0.03, минимум 20 пациентов в листе, 40 для разделения, subsample=1, без early stopping. Random state обеих моделей — 20261026, один поток леса. Параметры выбраны до расчёта этого сравнения, без подбора по метрикам. Полные параметры созданных estimator-ов сохранены в JSON.

Ограничения сложности выбраны с учётом малого числа событий. Это сравнение конкретных конфигураций; оно не определяет лучшую достижимую настройку каждого семейства. Для подбора понадобится внутренняя валидация. [Лес](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.ensemble.RandomSurvivalForest.html), [бустинг](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.ensemble.GradientBoostingSurvivalAnalysis.html).

Прогноз — выход `predict()` соответствующей модели: больший балл означает больший риск. Для леса это суммарная накопленная интенсивность по временам событий обучающего блока, для Cox и Cox-бустинга — балл log-hazard. Сравнивается порядок внутри каждого блока; баллы разных моделей/блоков не объединяются в общую числовую шкалу.

## Ограничения и следующий этап

Семейства моделей добавлены после просмотра результатов первых Cox-моделей; новые параметры зафиксированы до запуска, но эта когорта уже использована для развития исследования. Повторения зависимы; положительные разности не являются статистическим тестом. Выбор победителя по этой таблице потребует дальнейшей независимой проверки. Недоступные IPCW сохраняются с причиной, доступное число повторений приведено в JSON.

Следующий этап — расширение входной информации: заранее обоснованный набор признаков МРТ и регуляризованная модель, с отбором/настройкой только внутри обучающих блоков. Отдельно остаются выборочная неопределённость с переобучением, проверка пропорциональности рисков Cox и внешняя валидация. Абсолютные риски, калибровка и прогноз появления очагов по органам здесь не оценивались.

Полные метрики, настройки, версии и SHA-256: [model_comparison_results.json](model_comparison_results.json). Индивидуальные баллы и блоки — только в `data/derived/duke/baseline/` (`comparison_scores.csv`, `comparison_folds.csv`).
