# Duke: девять признаков МРТ и вложенная настройка Ridge Cox

674 пациентов / 47 отдалённых рецидивов; 20 повторений пятиблочной валидации по тем же пациентам, что в [предыдущем сравнении](model_comparison.md).

## Входы и настройка

Набор зафиксирован по происхождению и смысловым группам до сравнения с исходами: log-объём, solidity, elongation, entropy, homogeneity и четыре характеристики кривой контрастирования (максимум, время пика, uptake и washout). [Обоснование и первичные источники](../../research/duke-mri-feature-rationale.md). Возраст и остальные 520 опубликованных признаков не используются. Точные единицы/формулы части полей независимо не подтверждены; это анализ опубликованных числовых дескрипторов исходной МРТ, без пересчёта по DICOM.

Три модели: прежняя Cox по объёму без штрафа, Ridge Cox по объёму и Ridge Cox по всем девяти признакам. Для обеих Ridge-моделей alpha выбирается независимо из [0.1, 1.0, 10.0, 100.0, 1000.0] на трёх внутренних стратифицированных блоках исключительно внешней обучающей выборки. Критерий — Harrell C по сумме пар внутри внутренних блоков; при равенстве в пределах 1e-12 выбирается наибольшая alpha. Внутренний seed = 10 × внешний seed + номер внешнего блока.

Медиана, стандартизация и модель заново обучаются внутри каждого внутреннего блока и затем на всей внешней обучающей части с выбранной alpha. Все девять признаков входят в Ridge; штраф сжимает коэффициенты, автоматического отбора по исходам нет. Постоянные столбцы сохраняются; полностью пустой обучающий столбец Ridge заполняется нулём. Cox: ties=Efron, n_iter=200 для Ridge, tol=1e-9. Ошибки/предупреждения сходимости прерывают расчёт и не заменяются числом качества. [Вложенная валидация](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html), [Ridge Cox](https://scikit-survival.readthedocs.io/en/stable/user_guide/coxnet.html).

C-index агрегирован по парам только внутри внешних блоков; IPCW C до трёх лет — среднее по внешним блокам с оценкой цензурирования только по их обучающей части. Исход и правила смерти совпадают с прежним протоколом.

## Ограничения

Панель добавлена после предыдущих экспериментов на той же когорте. Вложенная настройка защищает внешние блоки от подбора alpha, но не заменяет независимую проверку всей последовательности исследовательских решений. Повторения зависимы; их диапазоны не являются доверительными интервалами. Большая часть признаков не проверялась на воспроизводимость по исходным МРТ; доступность сегментации и различия сканеров остаются ограничениями. Сохраняются неопределённость исходов, возможное нарушение допущений цензурирования/пропорциональности рисков и малое число событий. Абсолютный риск, калибровка и внешняя валидация здесь не оценивались.

Полные кандидаты alpha, внутренние метрики, статистики обработки, коэффициенты внешних моделей, версии и SHA-256: [mri_features_results.json](mri_features_results.json). Индивидуальные признаки, внешние/внутренние блоки и баллы сохраняются только в игнорируемой Git папке `data/derived/duke/mri_features/`.
