# База данных профилктики распространения опухолевого процесса

Исследовательский проект по созданию базы лонгитюдных медицинских данных и прототипа прогнозирования распространения опухоли. Система должна использовать историю обследований пациента и доступные сведения о лечении, чтобы оценивать появление новых опухолевых очагов и динамику заболевания.

**Статус:** постановка задачи и подбор данных. Датасет, модели и метрики пока не выбраны; реализация и результаты экспериментов ещё не представлены.

## Цель

Сравнить мультимодальные модели и ансамбли моделей на выбранном наборе данных и проверить возможность создания прототипа с измеримым качеством и умеренными требованиями к оборудованию.

Конкретный прогнозируемый показатель и горизонт прогноза будут определены после изучения доступных данных. Обнаружение изменений между уже выполненными обследованиями и прогноз будущих изменений оцениваются как разные задачи.

## Основные направления

- **Данные:** подбор открытого датасета, связывание обследований по пациентам и организация изображений в хронологическом порядке.
- **Прогнозирование:** сравнение отдельных мультимодальных моделей и ансамблей на общей выборке по единым правилам.
- **Прототип:** загрузка подготовленных данных, выполнение прогноза и сопоставление результата с фактическим исходом.
- **Поиск по базе:** дополнительный компонент для поиска медицинских изображений и связанных записей через естественный язык.

## Требования к данным

Приоритет — рак молочной железы. Другой вид рака допустим при наличии более подходящих данных и обосновании выбора.

| Параметр | Что требуется проверить |
| --- | --- |
| Повторные обследования | Несколько временных точек для одних и тех же пациентов |
| Временная структура | Идентификаторы пациентов, даты и порядок обследований |
| Изображения | Модальность и формат файлов; предварительно рассматриваются КТ и ПЭТ-КТ |
| Лечение | Доступность сведений о терапии |
| Исходы | Разметка или последующее обследование для проверки прогноза |
| Доступ | Условия использования и порядок получения данных |
| Объём | Желательно около 250 ГБ, ориентировочный предел — 1 ТБ |

Сравнение сценариев «с лечением / без лечения» остаётся исследовательским вопросом. Его постановка зависит от данных и требует отдельного обоснования.

## Модели и оценка

Планируется сравнить:

- простое базовое решение;
- ансамбль трансформеров и классических моделей машинного обучения;
- отдельную мультимодальную модель.

Qwen 27b рассматривается как кандидат. Точное название, версия, размер и поддержка изображений требуют уточнения. Ollama рассматривается как средство локального запуска моделей.

Для экспериментов необходимо определить целевой показатель, горизонт прогноза и соответствующие метрики. Разделение данных следует выполнять по пациентам, исключая использование будущих обследований во входных данных. Помимо качества, сравниваются время выполнения и потребление видеопамяти.
